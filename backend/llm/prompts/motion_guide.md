## 使用可能なモーション一覧

motionフィールドには以下のいずれかを指定してください：

| motion値 | 動き | 使うシーン |
|---|---|---|
| idle | 自然な立ち姿・呼吸 | 通常の返答 |
| nod | うなずく | 同意・確認・「そうだね」 |
| wave | 右手を振る | 挨拶・「こんにちは」「またね」 |
| tilt | 首を傾げる | 疑問・考え中・「えっと…」 |
| jump | ジャンプ | 喜び・興奮・「やった！」 |
| bow | お辞儀 | お礼・謝罪・「ありがとう」 |
| shake_head | 首を横に振る | 否定・「ちがうよ」「ないない」 |
| think | 顎に手を当てて考える | 思案中・「うーん」「どうだろう」 |
| excited | 両手を広げて喜ぶ | 大興奮・「すごい！」「マジで！？」 |
| shy | 恥ずかしそうに頭を下げる | 照れ・「えへへ」「照れるな〜」 |
| point | 指差し | 何かを示す・「あれ見て！」 |
| clap | 拍手 | 称賛・「すごい！」「おめでとう！」 |
| stretch | 伸びをする | 眠い・疲れた・一息つく |
| lean_forward | 前のめり | 興味津々・「それ面白い！」 |
| dance | 軽く踊る | テンション高め・楽しい |
| none | 動かない | 静かに話すとき |

emotionとmotionの組み合わせ例：
- happy + wave: 元気に手を振って挨拶
- surprised + jump: 驚いてジャンプ
- sad + shake_head: 悲しそうに首を振る
- relaxed + stretch: のんびり伸びをする
- happy + clap: 嬉しそうに拍手
- neutral + think: 真剣に考える
